ATLAS MEDIA

A private content-production and publishing automation tool. It turns finished scripts into videos and publishes them to the operator's own YouTube channels, with a backup copy kept in the operator's own Google Drive.

What it is

ATLAS MEDIA is software that its operator runs on their own computer. It prepares narrated videos from written scripts, renders them, and then uploads the finished result. It is not a public service: it has no public sign-up, no user accounts and no hosted back end, and it is run only by its operator.

This website exists only to describe the application and to publish its privacy policy.

Google integrations

The application connects to a Google account only after the account owner approves it on Google's own consent screen. It uses two integrations:

YouTube

Uploads each finished video, with its title, description, tags and thumbnail, to the authorised channel — by default as private. It reads back the channel's identity and the uploaded video's status to confirm that the upload reached the intended channel and succeeded.

Google Drive

Creates an archive folder and stores a backup copy of finished videos and related production files in it. It can only see files and folders that the application itself created, and it checks that each copy matches the original.

The application does not edit or delete existing videos, does not touch comments or playlists, and does not delete anything from Google Drive. Access can be withdrawn at any time — see the privacy policy.

Privacy

This website sets no cookies and runs no analytics or tracking scripts. The Privacy Policy describes exactly which Google user data the application accesses, why, where it is stored and how long it is kept.
